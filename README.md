# Tab Auto Rename

Tab Auto Rename змінює назви вкладок на вибраних сайтах. Можна задати звичайний текст або скласти назву з адреси сторінки.

Для роботи потрібен Firefox 140 або новіший.

## Як створити правило

1. Відкрийте сайт, для якого хочете змінити назву вкладки.
2. Натисніть кнопку Tab Auto Rename у браузері.
3. У полі **Match pattern** залиште запропоновану адресу сайту або змініть її. У полі **Title or template** введіть бажану назву. Для звичайного тексту плейсхолдери не потрібні.
4. Натисніть **Save rule**. Перегляньте приклад назви у блоці **Preview**.
5. Натисніть **Apply & close** і дозвольте доступ до сайту у вікні браузера.

Правило можна вимкнути, змінити або видалити у списку **Matching rules**. Якщо для сторінки підходить кілька правил, браузер застосує найточніше.

## Шаблони назв

Вставте плейсхолдери у поле назви. У вікні розширення натискання на плейсхолдер копіює його в буфер обміну.

| Плейсхолдер | Що підставляє |
| --- | --- |
| `{host}` | Повну назву хоста, наприклад `www.example.com` |
| `{domain}` | Основну частину домену, наприклад `example.com` |
| `{domain-1}` | Частину домену справа наліво: `com` |
| `{domain-1to2}` | Дві частини домену справа наліво: `example.com` |
| `{path}` | Увесь шлях після домену, без початкового `/` |
| `{path-1}` | Перший сегмент шляху |
| `{path-1to2}` | Перші два сегменти шляху |
| `{port}` | Номер порту, якщо він є в адресі |
| `{origname}` | Поточну назву вкладки |

Числа можна змінювати: наприклад, `{domain-1to3}` бере до трьох частин домену справа, а `{path-2to3}` — другий і третій сегменти шляху зліва.

Приклад для адреси `https://www.example.com:8443/docs/guide`:

```text
{origname} | {domain-1to2} | {path-1to2}
```

Результат: поточна назва вкладки, `example.com` та `docs/guide`.

## Приватність і доступ

Правила зберігаються у браузері. Розширення не збирає аналітику й не надсилає дані на зовнішні сервери. Доступ до сайту запитується окремо, коли ви натискаєте **Apply & close**.

Технічна інформація для розробників: [DEVELOPMENT.md](DEVELOPMENT.md).
